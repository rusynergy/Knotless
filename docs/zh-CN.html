使用文档

快速入门

安装 Knotless

下载适合 Windows 系统架构的安装程序并运行。安装后打开 Knotless，确认管理员权限请求。安装包已内置 Xray。

添加服务器

在「服务器」页面点击「添加服务器」，粘贴 vless:// 链接，或使用摄像头扫描二维码。使用订阅时，选择「添加订阅」并粘贴 HTTPS 订阅地址。

连接与检测

选择服务器并点击「连接」。首次启动默认选择 TUN 模式。闪电按钮会测试 TCP 端口，并通过服务器发送 HTTPS 请求。HTTPS 检测成功表示收到预期的响应。

路由规则

在「路由」页面设置默认行为与例外规则。以下示例让流量通过代理，访问私有 IP 地址时则直连。保存规则后重新连接即可生效。

default: proxy
ip(geoip:private) -> direct

连接设置

使用本地代理模式时，在浏览器中设置 SOCKS5 代理 127.0.0.1:10808 或 HTTP 代理 127.0.0.1:10809。使用 TUN 时，可在设置中选择 DNS 服务商和 TCP 或 DoH。在「内核」页面可以安装并选择下次连接使用的 Xray 版本。

更新与支持

在 GitHub Releases 中可下载各版本安装包、查看校验和及更新说明。
