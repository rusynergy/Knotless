Установка

Скачайте установщик для своей архитектуры Windows и запустите его. После установки откройте Knotless и подтвердите запрос прав администратора. Ядро Xray уже включено.

Добавление сервера

На странице «Серверы» нажмите «Добавить сервер». Вставьте ссылку vless:// или отсканируйте QR-код камерой. Для подписки выберите «Добавить подписку» и вставьте её HTTPS-адрес.

Подключение и проверка

Выберите сервер и нажмите «Подключиться». При первом запуске выбран TUN. Кнопка с молнией проверяет доступность TCP-порта и выполняет HTTPS-запрос через сервер. Успешный HTTPS-тест подтверждает, что запрос получил ожидаемый ответ.

Маршрутизация

На странице «Маршрутизация» укажите действие по умолчанию и исключения. Этот пример отправляет трафик через прокси, а для частных IP использует прямое подключение. Сохраните правила и переподключитесь.

default: proxy
ip(geoip:private) -> direct

Настройки соединения

В локальном режиме укажите в браузере SOCKS5 127.0.0.1:10808 или HTTP 127.0.0.1:10809. Для TUN в настройках можно выбрать DNS-провайдера и транспорт TCP или DoH. На странице «Ядро» можно установить и выбрать другую версию Xray для следующего подключения.

Обновления и помощь

Новые установщики, контрольные суммы и список изменений доступны в релизах GitHub.
